# 주간 VOC 카테고리 증감 리포트

비트버니(Bitbunny) 앱으로 들어오는 고객문의(VOC)를 자동으로 분류해서, "요즘 어떤 종류의 문의가 늘고 있는지"를 보여주는 리포트입니다. 이 저장소는 그 리포트 화면(웹페이지) 하나만 게시하기 위한 곳입니다.

---

## Quick Start

아래 링크를 열면 바로 리포트를 볼 수 있습니다. 설치나 로그인이 필요 없습니다.

**리포트 링크: https://carlie-dot.github.io/auto_cate-report/**

리포트 화면에서 표의 행을 클릭하면 더 자세한 항목이 펼쳐집니다. 자세한 보는 법은 아래 "리포트 사용법"을 참고하세요.

---

## 프로젝트 오버뷰

| 항목 | 내용 |
|---|---|
| 무엇을 | 고객문의(VOC)를 대분류 8개(광고·코인·포인트·걸음수·계정·로그인·교환·앱 오류·일반문의·혜택)로 자동 분류 |
| 어떻게 | 키워드 규칙이 아니라, AI(Claude)가 각 문의 내용을 직접 읽고 판단해서 분류 |
| 왜 | 어떤 유형의 문의가 늘고 있는지 빠르게 파악해서, 서비스 이슈를 더 일찍 발견하기 위함 |
| 원문 노출 | 없음 — 화면에는 카테고리별 집계 수치만 나오고, 고객이 실제로 쓴 문의 원문은 보이지 않습니다(개인정보 보호) |
| 갱신 방식 | 자동으로 실시간 갱신되지 않고, 새 데이터가 정리될 때마다 사람이 다시 게시합니다 |

## 프로젝트 설명

리포트는 세 부분으로 구성됩니다.

1. **대분류별 증감** — 최근 완결된 두 주(예: 지난 주 vs 그 전 주)를 비교해서 어떤 카테고리의 문의가 늘었는지·줄었는지 보여줍니다. 아직 끝나지 않은 이번 주 수치는 "참고치" 배지를 붙여 따로 표시해, 완결된 주 비교와 헷갈리지 않게 했습니다.
2. **전체 분포** — 한 달 전체 기준으로 각 카테고리가 차지하는 비중을 보여줍니다.
3. **일별 문의 추이** — 날짜별 문의 건수를 막대그래프로 보여주고, 기간을 직접 선택해서 원하는 구간만 볼 수 있습니다.

분류는 대분류 → 중분류 → 소분류의 3단계로 이뤄집니다(예: "광고" → "재생 중단" → "진행 멈춤"). 표에서 행을 클릭하면 이 세부 단계까지 펼쳐서 볼 수 있습니다.

## 프로젝트 구조

이 저장소에는 리포트 화면을 띄우는 데 필요한 파일만 있습니다.

```
index.html    리포트 화면 (위 Quick Start 링크가 여는 파일)
README.md     이 문서
```

문의 원본 데이터나 분류 과정에 쓰인 코드는 이 저장소에 없습니다 — 별도의 비공개 작업 환경에서 처리한 결과만 이 화면에 게시됩니다.

## 리포트 사용법

- **표 펼치기**: "대분류별 증감"·"전체 분포" 표에서 대분류 행을 클릭하면 중분류 목록이 나오고, 중분류를 다시 클릭하면 소분류까지 펼쳐집니다.
- **참고치 배지**: 아직 끝나지 않은 주(진행 중)의 수치에 붙는 표시입니다. 완결된 주 비교에는 포함되지 않은, 말 그대로 참고용 숫자입니다.
- **기간 검색**: "일별 문의 추이" 그래프 위 날짜 선택창으로 원하는 기간만 볼 수 있습니다. 기본값은 최근 30일입니다.
- **설명 아이콘( i )**: 표 제목 옆 작은 동그라미 아이콘에 마우스를 올리면 그 표를 보는 방법이나 기준이 추가로 설명됩니다.
